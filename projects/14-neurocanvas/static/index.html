First-layer weights, evolving

16 neurons · cyan = positive, rose = negative

At epoch 0 these are pure random noise. Within a few epochs blob- and stroke-shaped detectors appear in the middle. The border stays noisy: those pixels are almost never inked, so their weights never receive a gradient.

Honest caveat: these test digits come from the same synthetic generator as the training digits (different random seeds), so the score is optimistic. Real handwriting drawn on the pad is harder; see the Teach it tab to fix what it gets wrong.
