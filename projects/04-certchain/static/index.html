Issue a certificate

The record is hashed (canonical JSON + random salt), sealed in a Merkle tree, mined into a block and signed with the institution's Ed25519 key.

Revoke a certificate

Revocations are signed by the issuer and recorded on-chain; only the issuing institution can revoke.

Bulk issue from CSV

Columns: student_name, register_no, programme, cgpa, issue_date, cert_type. One block per batch; every row is validated first (all-or-nothing).

Block explorer

Each block stores the previous block's hash, a Merkle root of its records, a proof-of-work nonce and the issuer's Ed25519 signature. Click a certificate chip to verify it.
