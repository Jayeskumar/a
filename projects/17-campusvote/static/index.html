          How one vote stays both secret and checkable

          1. EligibilityRegister no. + one-time code → authority blind-signs a token it cannot see (Chaum RSA).
          2. AnonymityToken + signature + commitment go through a mix with no login; batches are shuffled.
          3. IntegrityEvery entry is hash-chained; RSA-signed checkpoints pin the head.
          4. SecrecyChoices hide inside SHA-256 commitments until the trustee opens them after close.
          5. VerifiabilityVoters check receipts; anyone recounts board.json, even in this browser.
