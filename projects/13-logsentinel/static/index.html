How a finding is made

  1. Signatures — URL-decode first, then regex for SQLi/XSS/traversal/scanner UAs.
  2. Correlation — sliding windows: N fails/IP, one IP ↔ many users, fails→success.
  3. Anomaly — per-IP EWMA + z-score on request rate, user-agent & path novelty.
  4. Every alert carries evidence, MITRE ATT&CK, and a response playbook.
