    How a donor is scored

    score = 0.30 x compatibility + 0.30 x proximity + 0.25 x response + 0.15 x fairness compatibility = 1.0 exact; -0.25 Rh- to Rh+; -0.25 other ABO proximity = exp(-travel_min / tau) tau: critical 25, urgent 45, planned 90 travel_min = 10 + haversine_km x 1.3 / 35 km/h x 60 response = (accepted + 2) / (alerts + 4) Beta(2,2) prior fairness = min(1, days since last alert / 14) Hard gates (excluded, reason shown): incompatible, unavailable, interval (90 d men / 120 d women), age 18-65, weight >= 45 kg, deferral
