How it works & privacy

Text model: Multinomial Naive Bayes over word unigrams, bigrams and character 3-4-grams with Laplace smoothing, written from scratch in Python.

Link model: logistic regression on 28 lexical URL features (IP host, '@' trick, punycode, look-alike brands, cheap TLDs, shorteners, entropy, phishing path words...). No DNS or web lookups.

Rule layer: India-specific scam patterns (KYC/PAN, EB disconnection, UPI collect, job fees, OTP requests, digital arrest...).

Combined score: noisy-OR, risk = 1 - (1 - 0.85 ptext) · ∏(1 - wrule) · (1 - 0.92 plink) · (1 - 0.55 pentity).

Privacy: the Python server runs on this laptop/phone network only. Nothing you paste is stored or sent anywhere.
